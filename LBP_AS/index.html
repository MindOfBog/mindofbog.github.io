    LBP Asset Studio

    LBP Asset Studio (f.k.a. Background Maker) is a tool that lets you create a variety of assets for LittleBigPlanet games. Originally made only to create custom Backgrounds, it's evolved into a tool that can make and edit plans (backgrounds, objects, materials, etc.) and bins (levels). The tool is still in development, so it may error or crash in some situations, if you are experiencing issues like that feel free to contact me on Discord to report the issues (please provide information on how it happened and on how to repeat it, otherwise I won't be able to do anything). Some features may not work or be available yet, like importing models and certain ThingParts, but they are planned to be added.

    How to run

    • The tool uses OpenGL, so the system you use it on needs to have a GPU that has those capabilities. Anything from the past decade should do, iGPU or dedicated, it doesn't matter.
    • It is written in Java and as of version 1.7 requires JRE 11 or up to run. (future versions may require a higher runtime)

    How to use

    Controls & Basic navigation

    • To navigate 3D space use the direction keybinds(1), the movement speed can be changed(2).
    • To rotate your view use the camera keybind(3) and move your mouse.
    • Floating Dropdown-tabs can be dragged with Left Button and expanded with Right Button
    • Combo-boxes can also be expanded with Right Button
    1. Keybinds can be changed under Settings>Controls
      Default:
      • Forward: W
      • Back: S
      • Left: A
      • Right: D
      • Up: Space
      • Down: Left Shift
    2. Set a specific speed in Settings>Controls>Move speed
      or dynamically increase or decrease it by scrolling up and down.
    3. Keybinds can be changed under Settings>Controls
      Default:
      • Camera: Middle Button

    At the top of the window you will see a few tabs: Scene, Archive, Project and Settings. In order to create what you want with this tool you will have to familiarize yourself with their purposes & functions.

    Here is where you will be constructing any "in world" assets, anything from levels, objects to backgrounds, and in the future even more complicated stuff. Anything you make here will be used to build into plans or bins.

    Loaded Elements List
    • On the right side of the window there will be a list of Elements, better known as "Things", that are in the current scene, you can select them from the list or by clicking on the models in the scene.
    • At the top of the list you have a "Load elements from PLAN/LEVEL" button, that allows you to load things from an existing loose .plan or .bin file.
    • You may also create a new thing completely from scratch if you need to. At the bottom of the list there is a "New" button, after creating an empty thing you can edit it and add parts onto it as you wish.
    Available Assets Tab

    In the Available Assets tab you have a list of all assets currently loaded(1). You may select any asset and it will automatically be placed into the scene. Primitive assets like mols or gmats will be placed in front of you, but plans or bins that have a position will be placed accordingly.

    If the list is empty, it could mean that:

    • There are no game files or profiles loaded.
    • Your game files or profiles are empty or corrupted.
    • Your mod doesn't contain any usable assets.
    1. At the top there should be a search box as well as filters you can use to find assets easier.
    Current Selection Tab
    • Once you have a selection you may edit the things you selected under this tab, you can change anything, Group, Parent and ThingParts, or even remove them or add new ones.
    • Multiple things can be edited at once. If you have multiple things selected, only the fields that your selection has in common, will be shown. For example, if you have two things selected and they don't have the same name, group or parent, those fields will be empty. And if those fields get changed, the changes will be applied to all selected things. This extends to ThingParts as well, only the parts that your selection has in common will appear in the list, and if you add, remove or edit a part, that change will be applied to your whole selection.
    Helpers Tab

    A few helpful settings and templates can be found here.

    • Level borders: shows the the bounds of a LBP level, as well as layers, the first three and the 13 extra ones that were added in LBP3.
    • Pod helpers: show an approximation of the Pod and Planets. (Useful when making pod backgrounds)
      • Checkboxes for LBP1, LBP2 and LBP3. (Yes, the locations are different fsr)
      • Pod cam moves your view approximately to where it would be in the pod.
    • Thing templates: spawn a few necessary things.
      • Level BG spawns a LevelSettings thing and a few scripts required for background creation.
      • LBP1 Pod BG spawns the planets and scripts required for LBP1 Pod background creation.

    In this tab you can load game files and profiles to use their assets in your scene.

    Loading game files

    • Avoid using game files from a disc game, digital games have their files decrypted, disk games need their base game data extracted and decrypted.
    • BIG Profiles are NOT profile backups, profile backups need to be decrypted/extracted to be usable so avoid using those.
    MAPs Tab

    Load or remove .mapfiles, multiple can be loaded at once.
    Can be found inside the games folder under the name blurayguids.map, and brg_patch.map for update content.

    FARCs Tab

    Load or remove .farcfiles, multiple can be loaded at once.
    Can be found inside the games folder under the name data_***.farc (or data.farc for LBP1), and cumulative_****.farc (or patch*.farc for LBP1) for update content.

    BIG Profiles Tab

    Load or remove bigfart files, multiple can be loaded at once.
    Can be found inside the game directory in a folder that has the same name as the game but with _USER* added to the folders name.

    Translations Tab

    If your loaded game data contains translation files, they will be listed here. You may select your language of choice, this will give proper names to levels and plans listed in Scene>Available assets, instead of raw file names.

    Here you will find a file tree, the files here will be exported to a .mod file once you're finished.

    • Folders can be collapsed and expanded by clicking on the icon on the left.

    • When right clicking or clicking on the three dots on the right of any entry in the tree, a context menu will appear:

      Clipboard operations

      Copying and pasting files only work within the tool, i.e. if you copy or cut a file in the file tree, you can paste it into the tool or even across different instances of the tool. BUT you cannot copy a file on your computer and paste it into the tool or vice versa.

      Mod entry (root folder)

      Behaves like a normal folder, however it cannot be deleted and it has an extra option:

      • Load Asset(s) from Mod allows you to load all contents of an existing mod into your project.
      Folders
      • Load Asset(s) lets you load loose files into the mod, they have to be LBP format files. e.g. .plan, .mol, .gmat, etc.
      • Build Scene is where you compile your scene to a .plan or .bin
      • Import allows you to convert and import regular format files to LBP format. e.g. .png -> .tex, .glb -> .mol
      • New Folder creates a new folder under the selected one.
      • Paste pastes files that were copied or cut.
      Files
      • Modify lets you change some things about the selected file.
      • Copy copies the selected file to your clipboard.
      • Cut copies the selected file to your clipboard and deletes it, so you can paste it elsewhere.
      • Replace lets you replace the selected file with a loose file.

    • Once you have all your files set up you can export the mod with the Export .MOD button. The resulting file can be installed like any LBP mod with Toolkit.

    • If you aren't finished with your project you can save your progress to a project file.
      Set your project path and save it with the Save Project button. This will output a executable .jar file, when you run it, it will try to run the tool from the location the tool was ran in, when you saved the project. If the LBP Asset Studio .jar file isn't in that location, you will be prompted to select a new path to the tools .jar.

    Anything in the tool can be tweaked here, everything from simple renderer settings (like FOV, culling, Z near/far) and changing the keybinds, all the way to changing the color scheme, fonts and cursor.

    Renderer Settings
    • No culling disables backface culling, currently necessary due to some meshes rendering incorrectly.
    • FPS set the FPS limit of the tool.
    • FOV lets you change the FOV, default FOV is an approximation of the in game FOV.
    • Z Near/Far lets you set the near and far values for the view projection of the 3D viewer, the values have to be ridiculously high because LBP works in a pretty big space.
    • AA Samples you can increase the sample count for MSAA, use 2 to 4 if you really mind the jagged edges, using more will cost you performance.
    • Outline Size change the width of the outline when selecting things in 3D space.
    • Outline Color change the color of the outline when selecting things in 3D space.
    • Border Colors (1-4) change the color of the level bounds, each is of a different layer set.
    • Earth Color change the color of the Earth helper
    • Pod Color change the color of the Pod helper
    GUI Settings
    • Gui Size scale the GUI down or up if the text is too big or small.
    • Backdrop/Primary/Secondary/Tertiary Colors change the color scheme of the GUI.
    • Font Color change the font color.
    • Font Header/Text change the font for headers and normal text, Comfortaa and GNU Unicode are available. GNU Unicode is less visually pleasing, however it supports every glyph, from European, Asian and many more languages. Useful when using translations.
    • Show FPS shows the FPS count of the tool in the title bar of the window.
    • Native File Dialogue uses a Java native file dialogue when opening or saving files. Useful on operating systems that aren't supported by TinyFD.
    Fonts, Cursors

    Not that anyone will ever do this, but the tool also has the capability to load external fonts and cursors. They need to be in a specific format, and be placed in a specific directory relative to the .jar. If for whatever reason you are interested in changing those, contact me on Discord and I'll explain how (not easy). Your custom font or cursor can also be added to the base tool if you're interested.

    Controls
    • Keybinds can be changed by clicking the button next to the bind you want to change, a new screen will appear where you can set any keyboard or mouse button as the new bind.
    • Move speed changes the directional move speed, can also be increased/decreased by scrolling.
    • Sensitivity changes the mouse sensitivity when dragging to rotate the view.
    Performance
    • Disable blur disables the blur effect behind certain GUI elements, improves performance
    • Disable SSAO disables the ambient occlusion pass, improves performance
    • Thread sleep time, can be increased to decrease CPU load, the Loader thread should be on a rather low sleep time, otherwise visual glitches may become noticeable.
